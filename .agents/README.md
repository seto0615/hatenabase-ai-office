# .agents — AI社員の定義

このディレクトリの `*.md` が、そのまま AI社員1名の定義になります。
ファイルを1つ足せば社員が1人増え、消せば1人減ります。アプリ側のコードを触る必要はありません。

`~/.claude/agents/*.md`（Claude Code のサブエージェント）と同じ「YAMLフロントマター＋本文がシステムプロンプト」の形式に揃えてあります。

## 形式

```markdown
---
name: researcher            # 社員ID（ファイル名と一致させる。英小文字とハイフン）
title: リサーチャー          # 画面に出る名前
role: 一次情報の調査         # 画面に出る肩書き
description: ...            # PMが「誰に振るか」を判断するときに読む1〜2文
model: claude-fable-5       # 使用モデル
effort: high                # low | medium | high | xhigh | max
tools:                      # 使えるサーバーツール（空なら [] と書く）
  - web_search
  - web_fetch
floor: 3                    # ビルの階（1〜5）
room: インテリジェンス部      # 所属部署（同じ階は同じ部署名にする）
emoji: 🔎                   # デスクに表示される絵文字
color: "#4C8DFF"            # 社員カラー
---

（ここから下がすべてシステムプロンプトとして渡されます）
```

## フィールドの意味

| フィールド | 必須 | 説明 |
|---|---|---|
| `name` | ✅ | 社員ID。PMが割り振るときの識別子。ファイル名と揃える |
| `title` | ✅ | 表示名 |
| `role` | ✅ | 肩書き。オフィス画面のデスクに表示される |
| `description` | ✅ | **PMが読む唯一の説明**。ここが曖昧だと正しく振られない |
| `model` |  | 省略時は `claude-fable-5` |
| `effort` |  | 省略時は `medium`。深く考えさせたい社員だけ `high` にする |
| `tools` |  | `web_search` / `web_fetch` のみ対応。省略時は空 |
| `floor` |  | 1〜5。省略時は1 |
| `room` |  | 部署名。同じ階の社員は同じ値にする |
| `emoji` / `color` |  | 見た目。省略時は既定値 |

## 特別扱いされるファイル

- `pm.md` — PMは唯一「分解と統合」を担当します。他の社員には振られません
- `README.md` — 社員としては読み込まれません

## 社員を追加する

1. `.agents/新しい社員.md` を作る
2. `npm run dev` を再起動する（ビルド時に `src/generated/agents.ts` へ変換されます）

以上です。ルーティングやUIの登録作業はありません。
